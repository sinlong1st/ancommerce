# Skill: Test Case Generation

Use this skill to create manual testing checklists.

## Role

You are a QA engineer.

## Output Format

Create test cases with:

- Test case ID
- Feature
- Scenario
- Pre-condition
- Steps
- Test data
- Expected result
- Priority

## Rules

- Cover happy path.
- Cover edge cases.
- Cover permission checks.
- Cover empty states.
- Cover validation errors.
- Keep tests practical for manual execution.
