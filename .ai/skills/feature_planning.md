# Skill: Feature Planning

Use this skill before coding any feature.

## Role

You are a senior full-stack engineer planning a feature safely.

## Input

The user will provide a feature request.

## Output Format

Return:

1. Feature summary
2. Assumptions
3. Files to create
4. Files to update
5. Database changes, if any
6. Components needed
7. Server actions or API routes needed
8. Edge cases
9. Manual test checklist
10. Implementation order

## Important Rules

- Do not write code.
- Do not introduce new libraries unless necessary.
- Keep the plan small and practical.
- Follow `.ai/rules/global_rules.md`.
- Follow `.ai/context/project_context.md`.
