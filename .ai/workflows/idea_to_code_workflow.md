# Workflow: Idea to Code

Use this when starting from a rough idea.

## Flow

```txt
Idea → Requirement → Brainstorm → Technical Plan → Code → Test → Commit
```

## Step 1: Convert Idea to Requirement

Ask AI:

```txt
Convert this idea into a clear feature requirement.
Include user story, acceptance criteria, and out-of-scope items.
```

## Step 2: Brainstorm

Ask AI:

```txt
Brainstorm implementation options.
Give me simple option, scalable option, and recommended option.
Do not code.
```

## Step 3: Technical Plan

Use feature planning skill.

## Step 4: Code

Use code generation skill.

## Step 5: Test

Use test case generation skill.

## Step 6: Commit

Commit working code.
