# UI Rules

## Design Style

Clean, simple, modern, and practical.

## Components

Use reusable components for:

- Navbar
- Footer
- ProductCard
- ProductGrid
- ProductDetail
- CartItem
- CheckoutForm
- AdminLayout
- AdminTable
- EmptyState
- LoadingState

## Tailwind Rules

- Use readable class names.
- Avoid extremely long className blocks when possible.
- Extract repeated UI into components.
- Make pages responsive.

## shadcn/ui

Use shadcn/ui for:

- Button
- Card
- Input
- Label
- Table
- Dialog
- Dropdown
- Form
- Select
- Badge

## Required States

Every major page should consider:

- Loading state
- Empty state
- Error state
- Success state

## Accessibility

- Buttons should have clear text.
- Inputs should have labels.
- Images should have alt text.
- Forms should be keyboard-friendly.
